# EG1163 高端检测观测与启动问题

2026-11-14，开发版新增HCS：13脚SDHIN相对14脚VS的检测等效电压。使用mV量程，在现有小信号波形栏显示，不改变原四栏结构，默认开启，并显示180mV（0.18V）阈值。长时间窗保留各周期检测峰值包络，放大后按周期内电流和高端导通状态重建，避免用平均电流掩盖检测峰值。

此信号沿用当前行为模型的采样电阻及上拉偏置关系，未包含检测脚寄生RC、尖峰等；不是任意接线下的SPICE节点求解。现有高端0.18V阈值、限流和后续5%最小脉宽控制本次未改动。

另提供可选HO−COM对地电压，按现有模型的HO−VS与开关节点电压相加。用户确认的实测深蓝通道是HO对COM，不能与HO−VS直接比较。实测其余通道：黄色SS、湖蓝ERRO、紫色CP，时基20µs/div；参数为补偿20kΩ＋10nF、SS100pF、CP220pF。

原慢运放拟合参数GBW等效3370.5266Hz、零点100Hz、第二极点4607.101Hz不能据此认为启动大信号已实测校准。诊断对照表明，恢复较快/静态响应会出现高端过流，但也导致明显持续振荡，因此本次只发布观测，不更改ERRO控制模型、不放宽20µA限流、不硬编码ERRO斜坡制造过流。启动大信号与稳态稳定性仍需一起重建验证。

检查：新增探针170/190mV阈值两侧数值及关断无偏置状态通过；实际浏览器确认HCS默认开启、波形存在、HO−COM定义可用且无脚本异常；在线/单文件仅替换相同保护显示脚本，其他芯片及用户版不变。构建脚本通过。旧check-eg1163.cjs仍有65000Hz历史断言而当前默认为72000Hz，不能据该旧断言回退当前振荡器参数。
