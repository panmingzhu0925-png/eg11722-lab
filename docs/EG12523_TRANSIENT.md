# EG12523 整图瞬态求解实验版

本版直接编译用户电路元件、连接和参数，从零初始能量开始计算，不再预充输出电容或回放预设稳态波形。当前确认图为114个器件条目，解析出37个电气节点、113个矩阵支路；J节点保留连接，原副边地分域。

## 使用
打开开发版后后台开始计算，首次运行可能需要数十秒。可选择64/96/192步每周期，停止按钮可随时取消。点击“载入最新确认图”会先备份浏览器原草稿。移动元件/标注不重算；修改参数或连接后可自动重算。元件参数区采用中文字段，变压器默认EQ4020、16:5:1、Lm=3mH。

默认观察VIN、VCC、输出、FB、SS、电感/原边电流和HO/LO。开关视图使用末2ms逐步记录，长时间视图保留整个启动过程。光耦开路复选框用于独立故障注入。

## 联合求解内容
- 交流正弦源、桥式整流和母线电容；启动电阻给VIN电容充电。
- VIN15V启动/9V以下关闭，启动电流30µA；OUT钳位17V，经实际电阻/二极管给VCC电容充电。
- 实际自举支路与驱动供电；门极电容、门极电阻及快关断二极管。
- 双管、体二极管、复位二极管、三绕组理想变压器及3mH励磁；可配置漏感、绕组电阻、C的ESR和L的直流电阻。
- 实际输出整流/续流及LC，负载在0.5V以下采用折返电导，避免恒流负载在未上电时主动拉成负电压。
- 光耦LED、CTR/响应时间、EG431等效跨导和实际补偿RC；反馈控制每个开关周期。
- SS10µA充电，CS RC、消隐及关断延时、46%最大占空比；CC最小脉宽用约96pC/Icc估计，仅0.8V限流顶端启用。
- FB开路70ms关断并保持，VIN欠压复位后重新启动；1V过流按周期峰值累计70ms的逻辑已实现，短路整机用例仍待专门验收。

## 已通过的整图检查
正常冷启动约0.72341s到15V；192步/周期时末1ms输出均值约23.9814V。该值是模型数值结果，不是实测精度承诺。

光耦开路：约0.72344s进入开路计时、0.79344s关闭PWM、1.06791s欠压关闭、1.36102s再次启动，持续故障时1.43104s再次关闭。保护时关闭指令立即生效，模拟引脚残余电压随后按电路衰减。

实际VIN电容加倍后，在0.75s尚未启动，证明参数参与充电过程。输入图的几何、位号、线路与标签数据不被求解器修改。

## 明确的等效假设和限制
- FB开路检测暂取4.9V且光耦电流小于1µA；用户确认的5V上拉和70ms延时不变。实际比较门限尚待确认。
- FB/CS采用无偏置2.8增益；驱动UVLO暂取5V。均不能当作内部实测参数。
- 431默认1A/V跨导、20µs等效响应；光耦默认CTR100%、10µs响应及LED1.1V/20Ω等效。可编辑，不代表具体器件精确模型。
- HO/LO/OUT使用受控电压源和0.25Ω等效串联电阻，门极充电负载回馈到VCC/自举，OUT供电负载回馈到VIN；拉灌电流饱和限幅尚未实现。
- 变压器为线性耦合模型，未模拟EQ4020磁芯饱和、磁损、温升或分布寄生；二极管未模拟实际反向恢复，未加入抖频。
- 粗步长会影响比较器交点及输出均值，192步/周期校核更接近本次设定值。不得通过固定输出或波形滤波掩盖差异。
- 这是整图联动实验版，尚未完成实测标定和浏览器视觉/用户验收，不是可替代样机验证的完整厂商SPICE模型。
