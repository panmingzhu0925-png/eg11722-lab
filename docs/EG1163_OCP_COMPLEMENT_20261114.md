# EG1163 高端过流后的下管联动修复

2026-11-14，用户更正：正常ERRO和SS超过CP时上管95%、下管5%；高端过流后上管进入5%最小脉宽。此前OCP缩短上管后，最大占空比分支仍将下管开通固定在95%位置，造成两管都窄、中间长双关断。

本次同步修正周期积分的下管开通时刻与实际门极边沿重建：OCP时在上管关断后经过200ns死区接通下管，周期末至下次上管也保留200ns。正常95/5不变；上管限流阈值和最小脉宽机制、下管负电流截断、ERRO/SS/CP模型均不改。若下管自身负电流保护触发，仍允许提前截短。

55/72/150kHz验证正常95/5、OCP5/95（均扣除死区）、两次200ns死区与无重叠；实际瞬态生成的OCP记录和门极边沿一致，负电流截断保留。检查脚本check-eg1163-ocp-complement.cjs。只更新开发版与同源EG1163单文件，用户版和其他芯片不发布。
