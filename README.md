# EG11722 交互式应用实验室

纯静态 HTML / JavaScript 网页，无需构建或第三方依赖。

## 本地使用
用 Chrome 打开 index.html 即可。支持原理图编辑、连线、参数调整、CCM/DCM 稳态波形与电路 JSON 导入导出。

## 在线访问
本仓库按用户授权公开，并通过 main 分支根目录部署 GitHub Pages。在线地址：https://panmingzhu0925-png.github.io/eg11722-lab/ 。也可通过本地 Chrome 打开 index.html 试用。浏览器端 JavaScript 可被访问网页的用户查看；若模型需要保密，后续应将求解放到服务端。

## 模型范围
单电感异步 Buck 的简化稳态行为模型。依据 EG11722 规格书典型参数实现 EN、最大占空比、峰值限流和过温条件判断。支持并联输出电容与电阻负载；不支持任意电路求解。VCC/VB 在芯片符号内抽象。尚未标定真实控制环路、启动和打嗝时序。仅供理解工作原理，设计需结合规格书、工程仿真和样机测试。

不包含原始 PDF、文档图片、Sites 配置及任何访问凭据。


## 原理图编辑操作
点击两个引脚即可连线，Esc 或右键取消；拖动元件移动，双击元件修改数值并按 Enter 应用。画布聚焦后 R 旋转、Delete 删除、Ctrl+Z 撤销，方向键微调位置。滚轮缩放，空格加拖动平移，可一键并联输出电容/电阻负载。草稿保存于浏览器本机，点击恢复上次草稿读取。


走线编辑：直接拖动线段平移；选中导线后拖动方形拐点。双击线段新增真实连接节点，普通模式拖动节点，Shift+点击节点开始分支接线。元件每按一次 R 顺时针旋转90°，连续四次回到原方向，端子标识与电气连接保持不变。走线路径和节点随电路 JSON 一起保存。


拖动结束时自动清理共线拐点与重复点。只有两根导线连接且走线共线的连接节点会自动合并；三路及以上分支节点保留。


芯片目录位于 chips.js，目前提供 EG11722 异步降压芯片的一套典型电路（初始约12V），用户自行修改元件与参数。W或工具栏连线按钮进入连线模式，可从导线或引脚起笔，接至导线或引脚；接入导线时自动拆分并建立真实分支节点。普通导线交叉不自动连接。


引脚与普通走线使用黑色；电解电容用弯极板及正极标记，贴片陶瓷用无极性平行极板。电容类型可在属性栏切换。页面启动先备份并恢复浏览器现有电路草稿，保留元件坐标、旋转角度、分支节点及路径；保存布局与电路按钮导出 JSON，建议另外保存文件备份。


EN引脚及默认470kΩ VIN上拉已建模，EN状态由电路连接决定，支持上拉/分压、接地和低压驱动。内部稳压管按用户提供结构作理想钳位；钳位值为用户确认的6.8V，采用理想钳位计算。规格书EN阈值为2.5V开启、2.3V关闭。未建模漏电流、动态电阻及热限制。旧版布局仅补充缺少的EN上拉，保留原元件与走线；已升级的电路不会自动补回用户主动删除的EN元件。


## 单文件离线版
将 eg11722-standalone.html 单独发给他人，下载后用 Chrome 双击打开即可，无需安装、服务器或联网。模型、样式和默认布局均已内置。浏览器草稿不随文件发送；另用电路 JSON 导出/导入迁移个人修改。更新源码后运行 node build-standalone.cjs 重新打包。在线版提供“下载单文件离线版”入口。

实际引脚：1 VCC、2 EN、3 GND、4 FB、5 VB、6 VS、7 IS、8 VIN，背面焊盘0 VIN。自举电容CBST=0.1µF接VB–VS；VCC去耦CVCC=1µF接VCC–GND。求解前检查这两组连接，供电与自举动态未进行晶体管级/时域求解。位号及数值分两行，引脚名位于芯片框内。


原理图可通过标题或示波器旁按钮折叠/展开。示波器通道按钮独立开关，IL与负载电流共用A轴，VS与VOUT共用V轴，输出交流纹波单独使用mV轴。各组共用时间窗，鼠标游标显示同一时刻的通道数值，电流及纹波保留固定量程。


## EG1654 连续模式 PFC
在线页面 eg1654.html；独立离线文件 eg1654-standalone.html。通过芯片下拉列表与EG11722互相切换；各芯片草稿分开保存。默认EG1654A 65kHz、600W、300µH、440µF、377.5V。支持工频包络和开关周期放大、多通道同步、可编辑网表、OCP/OPL/UVLO/BO/OTP/OVP边界提示。BO启动峰值与运行平均值模型参考onsemi AND8322；VM/VC稳态公式参考NCP1654和AND8321。EG1654的9.5V关闭阈值等数值仍以EG1654规格为准。未标定真实控制环路、启动时序、PF、THD、损耗及EMI。
资料：EG1654数据手册V1.0；600W方案说明；NCP1654设计计算表。原文件仅用于本地研究，未上传。补充公开参考：https://www.onsemi.com/download/data-sheet/pdf/ncp1654-d.pdf 、https://www.onsemi.com/pub/Collateral/AND8322-D.PDF 、https://www.onsemi.com/pub/Collateral/AND8321-D.PDF 。

无极性电阻、电感、陶瓷/薄膜电容按两端节点匹配，不限定a/b方向；二极管、电解电容及直流源仍校验极性。示波器时间轴可设置：EG1654工频ms/div与开关µs/div分别记忆；EG11722使用µs/div。横轴10格，所有通道使用同一时间窗及游标。
