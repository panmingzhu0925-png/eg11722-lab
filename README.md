# EG11722 交互式应用实验室

纯静态 HTML / JavaScript 网页，无需构建或第三方依赖。

## 本地使用
用 Chrome 打开 index.html 即可。支持原理图编辑、连线、参数调整、CCM/DCM 稳态波形与电路 JSON 导入导出。

## 私有开发与托管
本仓库仅用于私有保存源码及后续开发，未启用 GitHub Pages，也不自动发布网页。当前通过本地 Chrome 打开 index.html 试用；后续可部署至公司服务器并绑定公司域名。浏览器端 JavaScript 可被访问网页的用户查看；若模型需要保密，后续应将求解放到服务端。

## 模型范围
单电感异步 Buck 的简化稳态行为模型。依据 EG11722 规格书典型参数实现 EN、最大占空比、峰值限流和过温条件判断。支持并联输出电容与电阻负载；不支持任意电路求解。VCC/VB 在芯片符号内抽象。尚未标定真实控制环路、启动和打嗝时序。仅供理解工作原理，设计需结合规格书、工程仿真和样机测试。

不包含原始 PDF、文档图片、Sites 配置及任何访问凭据。


## 原理图编辑操作
点击两个引脚即可连线，Esc 或右键取消；拖动元件移动，双击元件修改数值并按 Enter 应用。画布聚焦后 R 旋转、Delete 删除、Ctrl+Z 撤销，方向键微调位置。滚轮缩放，空格加拖动平移，可一键并联输出电容/电阻负载。草稿保存于浏览器本机，点击恢复上次草稿读取。


走线编辑：直接拖动线段平移；选中导线后拖动方形拐点。双击线段新增真实连接节点，普通模式拖动节点，Shift+点击节点开始分支接线。元件每按一次 R 顺时针旋转90°，连续四次回到原方向，端子标识与电气连接保持不变。走线路径和节点随电路 JSON 一起保存。


拖动结束时自动清理共线拐点与重复点。只有两根导线连接且走线共线的连接节点会自动合并；三路及以上分支节点保留。


芯片目录位于 chips.js，目前提供 EG11722 异步降压芯片的一套典型电路（初始约12V），用户自行修改元件与参数。W或工具栏连线按钮进入连线模式，可从导线或引脚起笔，接至导线或引脚；接入导线时自动拆分并建立真实分支节点。普通导线交叉不自动连接。
